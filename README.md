# MogriChess

> **This is the original WPF version, and it is no longer being developed.**
>
> I am building a considerably better version of this game, which I intend to sell. It is a
> rewrite rather than an update: a proper game engine instead of WPF, real AI opponents, a
> tutorial, saved games, themes, and more than one language. This repository stays here, MIT
> licensed, for anyone who wants to read the original or borrow from it.

A chess-like game where capturing pieces gain the movement abilities of the pieces they capture.

The name comes from the "Calvin and Hobbes" comics. Calvin had a [Transmogrifier](https://calvinandhobbes.fandom.com/wiki/Transmogrifier) that could turn one thing into something else.
